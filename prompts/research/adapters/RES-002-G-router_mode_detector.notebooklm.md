> **조립 순서**: 코어 본문 → `---` → 본 어댑터 본문 순으로 붙여넣고 실행.

## 1. 실행 전 준비

판별할 **영상 1개만** 소스 체크박스에서 '선택'한 상태로 실행하세요.

## 2. 출처·시점 표기 규칙

NotebookLM은 답변에 **출처 인용을 자동으로 단다**. 따라서 인용 마커(`[1]` 등)를 텍스트로 직접 쓰려 하지 마라 — 인용은 플랫폼에 맡긴다.

- `[출처]` → 별도 표기 없이 생략. NotebookLM 자동 인용에 맡긴다.
- `[시점]` / `[출처+시점]` → 자동 인용에는 시각이 안 나오므로, 근거가 나온 **영상 시각을 본문에 `(mm:ss)` 형태로 직접 적어라.** (예: "…라고 말한다 (12:34)")

## 3. 환경 특화 제약

선택된 영상 소스 범위 내에서만 판단하라. 외부 지식·다른 소스를 끌어들이지 마라.

**콘텐츠 개요의 "명시 신호" 매핑**: NotebookLM 영상 소스는 보통 트랜스크립트 위주라 챕터 마커·설명란이 안 들어올 수 있다. 소스 안에 실제로 존재하는 신호만 근거로 삼아라 — 우선순위: ① 트랜스크립트에 명시된 챕터/타임코드 → ② 화자의 구두 섹션 선언("이제 ~를 보겠습니다") → ③ 소스에 포함된 설명란·제목 텍스트. 셋 다 없으면 개요를 지어내지 말고 "생산자 명시 구조 없음 — 2단계 deep의 암묵적 재구성 권장"으로 적어라.

## 4. 입력 전달

별도 입력 없음. 영상 1개를 선택하고 코어+어댑터를 붙여넣어 바로 실행하세요.
