## 1. 실행 전 준비 (NotebookLM)

1. 해체할 **단일 영상(YouTube/팟캐스트 URL 또는 트랜스크립트) 1개만을 체크박스에서 '선택'**한 상태로 실행하세요. (여러 개를 선택하면 구조가 섞입니다)
2. 영상 외 매체(논문·법령·기사 등)는 해당 매체의 코어를 사용하세요. (논문은 RES-002-A)
3. 코어 + 본 어댑터를 함께 복사하여 대화창에 붙여넣고 실행하세요.

## 2. 출처 플레이스홀더 치환 규칙 (횡단)

코어 출력 형식의 환경 중립 토큰을 다음 NotebookLM 형식으로 치환하여 출력하라:

| 코어 토큰 | NotebookLM 출력 형식 | 예시 |
|---|---|---|
| `[출처]` | 인용 마커 | `[1]` |
| `[시점]` | 타임스탬프 | `03:42` |
| `[출처+시점]` | 인용 마커 + 타임스탬프 | `[1] 03:42` |

**모든** 주장·인용·항목 끝에 해당 토큰을 빠짐없이 채워라. 토큰을 빈 채로 두지 마라.

## 3. 환경 특화 제약 (NotebookLM)

- **인용 강제**: NotebookLM의 인용 기능을 활용하여 모든 출처 토큰에 실제 원문 링크가 걸리는 인용 마커(`[1]`, `[2]` …)를 생성하라. 연구자의 기계적 검증 마찰을 최소화하기 위함이다.
- **선택 소스 한정**: 체크박스에서 '선택'된 해당 영상 소스 범위 내에서만 답하라. 선택되지 않은 다른 소스나 외부 지식을 끌어들이지 마라. (코어 제약 1의 NotebookLM 강제판)

## 4. 입력 전달

아래를 복사한 후, 괄호 안을 채워서 코어·어댑터 뒤에 이어 실행하세요. (모두 선택 입력 — 비워도 작동합니다)

- **(선택) 모드**: [`deep` / `brief` / `recipe` 중 하나 / 비워두면 AI 추천 모드로 작동]

- **(선택) 연구 맥락**: [예: "프롬프트 설계 영상 시리즈를 누적 정리 중"]
