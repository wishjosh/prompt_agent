# text_report_01_scan — 보고서 1차 스캔

상태: working draft
대상: 연구보고서 / 정책보고서 / 법정·비법정 계획서 / 데이터북 / 백서 / 실태조사 보고서 / 가이드라인 등 보고서 계열 비논문형 소스
주 실행 환경: NotebookLM 일반 채팅창
관련 프롬프트: text_report_02_deep

## 사용 전 메모

- 보고서 계열 소스 1편만 선택한다.
- NotebookLM 일반 채팅창에 아래 코드블록만 붙여넣는다.
- 결과의 `2. 심층 후보 및 연구자 선택 블록`에서 실제 분석할 `Target scope` 1개를 우선 골라 `text_report_02_deep`의 `DEEP INPUT BLOCK`에 붙인다.
- 채팅창 입력이 길어지면 `Target scope` 1개씩 나누어 실행한다.

## 복사해서 실행할 프롬프트

```text
선택된 보고서 계열 비논문형 글 중심 소스 1편을 1차 스캔한다.
대상은 연구보고서, 정책보고서, 법정·비법정 계획서, 데이터북, 백서, 실태조사 보고서, 가이드라인, 자료집 등이다. 학술논문·학위논문은 제외한다.

목표: 완결성 있는 구조 X-ray를 만들고, 연구자가 발췌독할 Target scope를 고를 수 있게 한다.

규칙:
- 첫 줄은 반드시 `# 1차 스캔_[소스 제목]`.
- 최상위 섹션은 0, 1, 2, 3뿐이다.
- 선택 소스만 사용한다. 외부 사실, 추정, 정책 조언 금지.
- 산문형 요약 보고서, 도입문, 결론 문단, 섹션 사이 연결 문장 금지.
- 원문 목차 순서를 보존한다. 원문 장/절을 최상위 섹션으로 승격하지 않는다.
- 원문에 없는 평가어, 수사, 새 개념명, 영어 개념어를 만들지 않는다.
- 정보가 없거나 불명확하면 `없음` 또는 `확인 필요`라고 쓴다.
- 위치는 반드시 페이지/장절을 먼저 쓰고 NotebookLM 인용 마커를 마지막에 둔다. 예: `p.8 [SOURCE_IMAGE_23]`.
- 페이지 번호만 단독으로 쓰지 않는다. 인용 마커가 보이지 않으면 `위치 미확인`이라고 쓴다.
- `SOURCE_IMAGE_N`은 줄여 쓰지 않고, 단독 위치 표기로 쓰지 않는다.
- 장/절 제목과 Scope 뒤에 쉼표, 대시, 빈 괄호, 남은 인용기호를 붙이지 않는다.

## 2. 심층 후보 및 연구자 선택 블록
아래 블록에서 실제 분석할 Target scope만 골라 `text_report_02_deep`의 `DEEP INPUT BLOCK`에 붙인다. 1차 스캔 전체를 붙이지 않는다. 서로 다른 장은 한 Target scope로 묶지 않고, 장 간 비교는 Cross-scope request에 적는다.

### 2-A. 1차 스캔 내용

- Other selectable range: [구조 X-ray에 있으나 후보로 뽑지 않은 장/절]

### 2-B. Target scope 후보
아래 Target scope는 자동 후보이며 연구자가 유지·수정·삭제할 수 있다. 발췌독 가능한 장/절 단위로 필요한 만큼 작성한다.

#### Target scope 1
- Scope: [단일 장/절 또는 발췌 가능한 범위] [위치+인용]

- Additional analysis focus: [발췌독 때 볼 세부 초점]
```
