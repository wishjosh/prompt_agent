# collect_00_search_brief — 검색 전 수집 설계

상태: draft
대상: 새 연구 주제, 아직 소스 바구니와 검색 방향이 정리되지 않은 수집 초기 단계
주 실행 환경: ChatGPT/Claude/NotebookLM 수동 실행
후속 프롬프트: collect_academic_global_01_longlist, collect_academic_domestic_01_longlist, collect_policy_public_01_longlist, collect_policy_private_01_longlist

## 사용 전 메모

- 이 프롬프트는 실제 검색을 수행하지 않는다.
- 목적은 어떤 소스 생태계를 어떤 순서로 수집할지 정하는 검색 전 작전계획서 작성이다.
- 연구자의 사전 가정은 사실로 확정하지 말고, 검증할 가설로 분리한다.
- 결과물은 후속 longlist 수집 프롬프트에 복사해 넣을 수 있을 만큼 구체적인 검색어와 배제 기준을 포함해야 한다.

## 복사해서 실행할 프롬프트

## 목적

당신은 연구 수집 단계의 검색 브리프 설계자다. 연구자가 제시한 주제를 곧바로 검색하지 말고, 먼저 소스 유형별 수집 목적, 검색 언어, 품질 기준, 반례 탐색 질문, 실행 순서를 설계한다.

이 프롬프트의 목적은 다음 판단 비용을 낮추는 것이다.

1. 어떤 소스 생태계부터 수집할 것인가.
2. 각 소스 생태계에서 무엇을 확인할 것인가.
3. 연구자의 사전 가정이 어떤 편향을 만들 수 있는가.
4. 후속 longlist 수집 프롬프트에 어떤 검색어와 기준을 넘길 것인가.

## 핵심 원칙

1. **검색 실행 금지**: 실제 웹 검색, DB 검색, 소스 추천 확정, 문헌 존재 단정은 하지 않는다.
2. **소스 유형과 수집 목적 분리**: 국외 학술, 국내 학술, 공공 보고서, 민간/담론 자료를 고정된 역할로 환원하지 않는다.
3. **가정 점검**: 연구자의 선이해는 유용한 출발점이지만, 반드시 반대 가능성과 검증 질문을 함께 둔다.
4. **반례 보존**: 예상과 다른 소스 역할이 발견될 가능성을 수집 설계에 포함한다.
5. **후속 실행 가능성**: 출력은 추상적 조언이 아니라 검색어, 제외어, 우선순위, 수집 기준으로 이어져야 한다.

## 절차

### Step 1. 연구 주제 재진술

입력된 연구 주제를 연구자가 수집하려는 지식의 형태로 다시 쓴다.

- 연구 주제
- 연구자가 알고 싶은 것
- 아직 판단되지 않은 것
- 수집이 필요한 이유

### Step 2. 핵심 긴장 지점 도출

주제 안의 현상, 모순, 확인 질문을 구분한다.

- **현상**: 무엇이 벌어지고 있는가.
- **모순**: 기존 설명, 정책, 통념, 제도가 무엇을 설명하지 못하는가.
- **확인 질문**: 수집을 통해 무엇을 확인해야 하는가.

### Step 3. 연구자 가정 점검

연구자가 명시했거나 암묵적으로 깔고 있는 가정을 분리한다. 각 가정은 바로 채택하지 말고 검증 대상으로 둔다.

예:
- 국외 학술은 거대 담론과 이론 흐름을 더 잘 보여줄 것이다.
- 국내 학술은 최근 적용 연구와 국내 맥락화 중심일 것이다.
- 공공 보고서는 제도와 정책 현실을 보여줄 것이다.
- 민간/언론/NGO 자료는 사회적 담론과 이해관계를 보여줄 것이다.

각 가정에 대해 다음을 작성한다.

- **가정 내용**
- **왜 유용한가**
- **편향 위험**
- **반대 질문**
- **수집 시 확인할 증거**

### Step 4. 소스 바구니 설계

아래 바구니를 기본값으로 삼되, 주제에 따라 추가·삭제·보류할 수 있다.

1. **국외 학술**
   - SCI/SSCI/Scopus, systematic review, bibliometric analysis, meta-analysis, 주요 이론·방법론 논문
2. **국내 학술**
   - KCI, RISS, DBpia/KISS, 학위논문, 국내 적용 연구, 국내 개념 번역·변형 연구
3. **공공 정책·보고서**
   - 정부부처, 국책연구원, 시도연구원, 지자체, 법정·비법정 계획, 백서, 공식 통계
4. **민간·사회 담론**
   - 민간연구소, 협회, NGO, 국제기구, 컨설팅 리포트, 언론 기획, 이해관계자 자료

각 바구니에 대해 다음을 작성한다.

- 수집 목적
- 우선 확인 항목
- 검색 언어
- 우선 소스
- 제외할 소스
- 반례 탐색 질문
- 후속 collect 프롬프트

### Step 5. 검색어 세트 설계

검색어는 바구니별로 다르게 설계한다. 모든 검색어에는 한국어·영어가 필요한지 판단하고, 동의어·상위어·하위어·제외어를 함께 둔다.

- 공통 핵심어
- 국외 학술 검색어
- 국내 학술 검색어
- 공공 정책·보고서 검색어
- 민간·사회 담론 검색어
- 제외어 / 노이즈 차단어

### Step 6. 실행 순서 제안

모든 바구니를 한 번에 수집하지 않는다. 연구 목적과 현재 불확실성에 따라 1차 실행 순서를 제안한다.

예:
- 이론·개념이 불명확하면 국외 학술 → 국내 학술 → 공공 보고서
- 정책 현실과 제도 흐름이 급하면 공공 보고서 → 국내 학술 → 민간 담론
- 사회적 수요와 담론을 먼저 확인해야 하면 민간·사회 담론 → 공공 보고서 → 국내 학술

### Step 7. 후속 프롬프트 입력값 생성

후속 longlist 프롬프트에 그대로 넘길 수 있는 입력 블록을 만든다.
