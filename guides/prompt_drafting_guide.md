# 프롬프트 작성 가이드

## 작성 전 질문

- 이 프롬프트는 연구자의 어떤 판단 비용을 낮추는가?
- 대상 소스는 무엇인가: 논문, 보고서, 계획서, 영상, 녹취록, 기타?
- NotebookLM에서 어떤 소스를 몇 개 선택해야 하는가?
- 출력 후 연구자가 바로 할 수 있는 다음 행동은 무엇인가?

## 작성 규칙

- 하나의 프롬프트는 하나의 파일에 둔다.
- 목적, 대상, 사용 전 메모, 복사해서 실행할 프롬프트, 출력 형식을 한 파일 안에 둔다.
- 사용 전 메모에는 실행자가 할 일을 쓰고, 모델 지시는 복사해서 실행할 프롬프트 본문에만 쓴다.
- 검증 전에는 코어/어댑터/빌드로 분리하지 않는다.
- 원문 구조를 보존해야 하는 프롬프트에는 임의 재구성 금지 문구를 넣는다.
- 중요한 항목에는 인용 마커와 위치 표기를 강제한다.
- 확인되지 않는 내용은 추정하지 말고 "확인되지 않음"으로 남긴다.

## 좋은 초안의 기준

- 실행 전 준비가 명확하다.
- 출력 구조가 복붙해서 바로 쓸 수 있다.
- 연구자가 deep, 비교, 인용, 폐기 중 다음 행동을 정하기 쉽다.
- 멋진 문장보다 근거 위치와 구조가 우선한다.
